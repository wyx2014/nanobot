# 打电话

用户说“给某人打电话”时，桌面 gateway 会直接按姓名查分机表并向本机话机发送拨号指令。姓名唯一匹配后立即拨打，无需让用户再说分机号或重复确认。也可用 `/call 姓名`、`/call 号码`、`/call 挂断`。

实际执行代码在 `nanobot/command/t46u.py`，由 `nanobot/agent/loop.py` 在聊天命令阶段调用。它读取分机表、解析主叫话机，并请求 Yealink `ConfigManApp.com` 接口；技能目录提供使用说明和通讯录。

真实通讯录放在本机工作区 `skills/call/内部分机信息表.md`；技能目录的同名文件仅提供表头模板。表头为 `分机短号`、`显示名称`、`显示名称(英文)`、`终端IP`、`分机注册状态`。姓名和英文名均可查询；重名、缺号或 `xxx` 示例数据不能拨打，应请用户提供准确姓名或完整数据。

本机只需配置一次工作区 `skills/call/config.json`：`caller` 为自己的四位分机，`username` 和 `password` 为话机登录凭据。程序会从通讯录中该主叫分机所在行读取 `终端IP`；如果表中没有主叫分机，再设置 `phone_ip`。其他可选项见 `config.example.json`。不要将本机主叫和凭据写入内置技能或聊天消息。

gateway 已处理拨号或挂断时，直接转述返回结果，不要再调用脚本、`curl` 或模型工具重拨。返回成功只表示话机接受指令，是否接通以话机状态为准。
